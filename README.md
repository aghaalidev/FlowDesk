# FlowDesk 🚀
### SaaS Task & Workflow Management System

FlowDesk is a cloud-based SaaS platform that helps teams manage 
their tasks, projects, and workflows efficiently in one place.

---

## 🔗 Live Prototype
👉 https://v0-flowdesk-saas-app-seven.vercel.app/login

## 📄 Project Documents

---

## ✨ Features
- 🔐 Login & Authentication
- 📊 Dashboard with Task Summary Cards
- 📋 Kanban Board (Todo, In Progress, Completed)
- 👥 Team Members Management
- 🔔 Notifications System
- 📈 Reports & Analytics
- 📱 Mobile Responsive UI

---

## 🛠️ Tech Stack
- Frontend: React.js / Next.js
- Backend: Python (FastAPI)
- Database: PostgreSQL
- Auth: JWT + bcrypt
- Hosting: Vercel + Render
